# 日富一日·钱途光明 · 工作台管理说明（rifuyiri）

> 本文件夹是「日富一日·钱途光明」手机端工作台的**完整可运行目录**。
> 双击 `index.html` 即可在浏览器 / 安卓直接打开使用，无需任何服务器或安装。

---

## 一、文件归类与用途

| 文件 | 类别 | 用途 | 你需要动它吗？ |
|------|------|------|----------------|
| `index.html` | 入口 | 页面骨架 + 加载样式/脚本，**双击它打开** | 一般不用 |
| `css/style.css` | 样式 | 外观：配色、圆角、卡片、布局、深浅色 | 想换主题/配色时改 |
| `js/config.js` | **数据配置** | ★ 所有可编辑数据：AI 工具列表、名言、冷笑话、每日推荐 | **每月更新主要改这里** |
| `js/app.js` | 程序逻辑 | 全部功能代码（待办/随记/额度/账本/AI+等） | 一般不用 |

> 归类思路：**数据（config.js）与代码（app.js）分离**，外观（style.css）独立。
> 你日常"管理更新"几乎只碰 `js/config.js`。

---

## 二、常见更新操作

### 1. 每月更新 AI 工具（最常做）
打开 `js/config.js`，找到 `aiTools` 数组，按现有格式增删即可：
```js
{ name:'工具名', url:'https://...', cat:'对话', region:'cn' }   // region: 'cn'=国内 / 'foreign'=国外
```
- 改完刷新页面即生效，无需其他操作。
- 顶部 `aiUpdated` 字段改成当前月份（如 `'2026-08'`），页面会显示更新时间。

### 2. 换背景 / 配色
打开 `css/style.css`，修改 `:root` 里的颜色变量（如 `--primary`、`--primary2`、`--bg1` 等）。
深色模式在 `body.dark` 里对应调整。

### 3. 换名言 / 冷笑话 / 每日推荐
都在 `js/config.js` 顶部：`enQuotes`（英文鸡汤）、`cnJokes`（中文冷笑话）、
`movies`/`tvs`/`books`（每日推荐池），直接增删文本即可。

### 4. 改完代码后，让手机/访客强制刷新（防缓存 · 重要）
`index.html` 里 `css/style.css`、`js/config.js`、`js/app.js` 的引用都带 `?v=日期` 版本号。
**每次修改这三个文件后，必须把 `?v=` 后面的数字改掉**（如 `?v=20260730` → `?v=20260731`），
否则手机浏览器和已访问过的访客会一直用旧的缓存文件，表现为"页面能看但点了没反应"。
改完重新部署即可，无需其他操作。

---

## 三、数据备份（重要）
- 页面右上角「⤓」按钮 = **导出全部数据**（下载为 JSON 文件）。
- 每 **15 天**未导出，按钮会出现**红点提醒**，导出一次后红点消失。
- 换设备或重装前，务必先点导出，再用「⇪」导入恢复。
- 运行时数据（待办、账本等）存在浏览器 localStorage，清缓存会丢，请定期导出。

## 四、目录现状
```
rifuyiri/
├── index.html        # 入口，双击打开
├── README.md         # 本说明
├── css/
│   └── style.css     # 样式
└── js/
    ├── config.js     # ★ 数据配置（AI工具/名言/笑话/推荐）
    └── app.js        # 程序逻辑
```

> 后续要加新页面：在 `js/app.js` 的 `NAV` 数组追加一项，并在 `PAGES` / `ACTIONS` 注册即可，
> 无需改动 `index.html`。
